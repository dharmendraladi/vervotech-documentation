The Vervotech Mappings Portal offers a comprehensive overview of all your configured providers. For each provider, the following details are displayed:

- **Provider Name:** The name of the content provider.
- **Provider Key:** A unique identifier used to reference the provider when running the downloader.
- **Account ID:** Your associated Vervotech account identifier. 
- **Downloader Type:** Indicates the type of downloader assigned to the provider.
- **Disabled Status:** Reflects whether the provider is currently active or disabled.

**Mapping Provider Content**
Provider content is typically processed and mapped within 1 to 48 hours. Providers fall into the following categories:

- **Master Providers**
Vervotech downloads static content directly from the provider's system on a scheduled basis using Vervotech’s master credentials.

- **Exclusive Providers**
Vervotech downloads static content from the provider's system on a scheduled basis using your provided credentials.

- **FTP Providers**
You can upload a CSV file via FTP, file processing can be triggered manually after the upload.
