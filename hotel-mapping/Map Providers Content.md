We usually map and publish provider mappings as well as content within 1 to 48 hours.

- **Master Providers:**

We download the static content from provider systems on periodic schedules for each provider using our master credentials.

- **Self Providers:**

```
We download the static content from provider systems on periodic schedules for each provider using provider credentials entered by you. 

```
- **FTP Providers:**

You can upload a CSV file directly to our system using FTP, then the file processing can be triggered manually by you.

If you plan to start mapping from the web portal then follow the below steps,

1. Login to Vervotech Mappings Portal.

2. Go to ''Load Providers Content" section from the navigation menu.

3. Enter the SFTP folder path of your content files and click on start mapping.

You can also initiate the FTP-based mapping through API, http://docs.vervotech.com/start-mapping-by-ftp-folder-16383699e0
